# GoldPrice Web 📈

GoldPrice Web 是一个现代化、纯前端的跨平台行情看板工具。它是由原本的 macOS 桌面悬浮小组件完全移植而来的 Web 版本，完美复刻了原版的 Glassmorphism (毛玻璃) 悬浮窗美学与核心业务逻辑。

## ✨ 特性

- **纯前端架构**：完全使用 HTML5、CSS3 (原生 CSS 变量 + Flex/Grid 布局) 和 Vanilla JavaScript 构建。无需任何后端服务，开箱即用。
- **无缝的数据抓取 (跨域绕过)**：利用 `JSONP` 动态脚本注入技术，在浏览器端直接从东方财富和天天基金拉取实时盘口数据和基金估算净值，成功绕过了浏览器的 CORS 限制。
- **实时盘中估值**：支持配置多只基金（通过 6 位代码），每 60 秒自动刷新盘中估值，每 5 秒刷新大盘（上证指数）和黄金（AU9999）的实时行情。
- **安全的数据持久化**：所有持仓数据（成本、份额等）均使用浏览器的 `localStorage` 在本地加密存储，绝对不会上传至任何云端。
- **Glassmorphism 极致美学**：使用现代 CSS `backdrop-filter` 实现了深色模式下的半透明磨砂玻璃效果，界面精美、干净、无广告。

## 💻 本地运行

因为这是一个纯静态项目，您可以克隆代码后直接双击 `index.html` 运行，或者使用本地静态服务器以获取最佳体验：

```bash
git clone https://github.com/zhyio/GoldPriceWeb.git
cd GoldPriceWeb
npx http-server . -p 8080
```

打开浏览器访问 `http://localhost:8080` 即可。

## 🛠 核心功能

- **添加基金**：输入 6 位基金代码和初始持仓金额，系统自动拉取该基金的实时净值估算并建立持仓。
- **动态盈亏计算**：根据当前实时估算净值与持仓成本，动态计算并呈现红绿色的**总收益**与**今日盈亏**。
- **补仓/减仓**：点击对应基金后的 `⋯` 按钮，可以进行智能的金额加减仓。如果是减仓，系统会根据当前净值精确计算扣除的份额与成本；若全部减完，系统会自动清零。
